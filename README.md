# Retro OS Portfolio

This isa a retro-inspired personal portfolio website designed as a desktop operating system interface. The project presents my work experience, education, skills, projects, and contact details in an interactive, nostalgic layout inspired by classic desktop computing.

## Features

- Desktop-style portfolio layout
- Interactive Windows-based navigation
- Embedded project, experience, education, and skills sections
- Downloadable CV button
- Music player and retro interface details
- Responsive layout for desktop and smaller screens
- Clean HTML, CSS, and JavaScript implementation without a framework

## Tech Stack

- HTML
- CSS
- JavaScript
