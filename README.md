# Retro OS Portfolio

A retro-inspired personal portfolio website designed as a desktop operating system interface. The project presents work experience, education, skills, projects, and contact details in an interactive, nostalgic layout inspired by classic desktop computing.

## Overview

This portfolio is built as a single-page web experience with a playful retro OS aesthetic. Visitors can explore sections through desktop-style icons, floating windows, and an embedded music player, creating a memorable and highly visual personal brand presence.

## Features

- Desktop-style portfolio layout
- Interactive Windows-based navigation
- Embedded project, experience, education, and skills sections
- Downloadable CV / résumé button
- Music player and retro interface details
- Responsive layout for desktop and smaller screens
- Clean HTML, CSS, and JavaScript implementation without a framework

## Getting Started

### Prerequisites

- A modern web browser
- A local web server is recommended for the best experience

### Run locally

1. Clone the repository:

```bash
git clone https://github.com/AishShafa/retro-os-portfolio.git
cd retro-os-portfolio
```

2. Start a local web server:

```bash
python -m http.server 8000
```

3. Open the site in your browser:

```text
http://localhost:8000
```

## Usage

- Open the landing page to view the retro desktop layout.
- Click the desktop icons to open portfolio sections.
- Use the interface to browse projects, work history, skills, and contact details.
- Use the CV shortcut to download the resume.

## Customization

To tailor the portfolio to a different user profile:

- Update the personal details in `index.html`
- Edit the content sections in the individual HTML pages
- Adjust styling in `styles.css` and files under `styles/`
- Replace or update assets in `assets/`

## Notes

This is a front-end portfolio site with no build pipeline or dependency installation required. It is designed to be simple to deploy to GitHub Pages, Netlify, Vercel, or any static hosting platform.
